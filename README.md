# حساباتي

تطبيق ويب يتثبت على الموبايل (PWA) لتسجيل المصروفات اليومية وفصل فلوس العهدة عن الفلوس الشخصية، مع إن الاتنين في نفس المحفظة ونفس الحساب.

## الفكرة في سطرين

- كل عملية بتتسجل على **حساب** (الفلوس فين: كاش، بنك، فودافون كاش...) وعلى **محفظة** (الفلوس دي بتاعة مين: شخصي أو عهدة شركة).
- **فلوسي = إجمالي أرصدة الحسابات − أرصدة العهد**.
- البنود مستويين: رئيسي وفرعي، ولكل محفظة (شخصي/كل عهدة) شجرة بنود مستقلة.

## تشغيله على جهازك

لازم يشتغل من سيرفر، مش بفتح `index.html` مباشرة، عشان الـ ES modules والـ Service Worker:

```bash
cd hesabaty
python3 -m http.server 8080
# افتح http://localhost:8080
```

## نشره على GitHub Pages (مجاناً)

1. اعمل repository جديد على GitHub، مثلاً `hesabaty`.
2. ارفع محتوى الفولدر ده (مش الفولدر نفسه) على فرع `main`:
   ```bash
   cd hesabaty
   git init && git add . && git commit -m "first version"
   git branch -M main
   git remote add origin https://github.com/USERNAME/hesabaty.git
   git push -u origin main
   ```
3. من الـ repo افتح **Settings → Pages**، واختار Source: `Deploy from a branch`، وBranch: `main` / `root`.
4. بعد دقيقة هيبقى على `https://USERNAME.github.io/hesabaty/`.

## تثبيته على الموبايل

- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
- **آيفون (Safari):** افتح الرابط ← زرار المشاركة ← **إضافة إلى الشاشة الرئيسية**.
- **اللاب (Chrome/Edge):** أيقونة التثبيت في شريط العنوان.

> **مهم:** على الآيفون لازم تثبّت التطبيق على الشاشة الرئيسية، لأن Safari ممكن يمسح بيانات المواقع اللي مش متثبتة لو ما اتفتحتش فترة. ولو المزامنة شغالة، بياناتك محفوظة على السحابة في كل الأحوال.

## تجهيز المزامنة (Supabase) — مرة واحدة

1. اعمل حساب مجاني على [supabase.com](https://supabase.com)، ودوس **New project**. اختار أي اسم وكلمة سر لقاعدة البيانات، وأقرب منطقة ليك (مثلاً Frankfurt).
2. لما المشروع يجهز، افتح **SQL Editor ← New query**، والصق محتوى ملف `supabase.sql` كله، ودوس **Run**.
3. افتح **Authentication ← Sign In / Providers ← Email**، واقفل **Confirm email** ودوس Save. ده عشان تقدر تدخل على طول من غير تأكيد بالإيميل. ولو سبته مفتوح، هتأكد الحساب من الإيميل مرة واحدة.
4. افتح **Project Settings ← API** (أو **Data API**)، وانسخ:
   - **Project URL** (زي `https://abcd.supabase.co`)
   - **anon public key** (بيبدأ بـ `eyJ...`)
5. في التطبيق: **الإعدادات ← المزامنة**. الصق الاتنين، واكتب إيميل وكلمة سر، ودوس **حساب جديد**. ده على أول جهاز بس.
6. على أي جهاز تاني: نفس البيانات، بس دوس **دخول**. لو الجهاز جديد، التطبيق هينزّل بياناتك عليه.

> ادخل على الجهاز التاني قبل ما تسجل عليه أي عمليات، عشان ما يحصلش تكرار. ولو حصل، التطبيق هيسألك: تاخد بيانات السحابة ولا تدمج الاتنين.

**إزاي المزامنة شغالة:** كل حاجة بتتسجل على الجهاز الأول، فالتطبيق بيشتغل عادي من غير نت. وبعد أي تعديل بثانيتين، وكل دقيقة، ولما النت يرجع، التطبيق بيرفع التعديلات وبينزّل تعديلات الأجهزة التانية. لو نفس العملية اتعدلت على جهازين، آخر تعديل هو اللي بيكسب. الأيقونة اللي فوق في الرئيسية بتوضح الحالة: أخضر يعني اتزامن، وأصفر جاري، وأحمر فيه مشكلة، ورمادي مفيش نت.

**الأمان:** كل مستخدم بيشوف بياناته هو بس (Row Level Security في `supabase.sql`). الـ anon key مش سر، ومن غيره التطبيق مايقدرش يكلم Supabase. اللي بيحمي بياناتك هو الإيميل وكلمة السر.

## نشر تحديث

أي تعديل في الملفات: غيّر `VERSION` في `sw.js` (مثلاً `v0.2.1`) قبل الرفع، ولو ضفت ملف جديد ضيفه في قايمة `FILES` في نفس الملف. ده اللي بيخلي الأجهزة تنزّل الملفات الجديدة بدل القديمة اللي في الكاش.

| الملف | الدور |
| --- | --- |
| `index.html` | الصفحة الوحيدة |
| `css/app.css` | التصميم (فاتح وغامق تلقائي، RTL) |
| `fonts/` | خط Alexandria من Google Fonts (رخصة OFL)، متخزن محلياً عشان الشغل أوفلاين |
| `js/app.js` | البداية: الراوتر، شريط التنقل، القفل بالرقم السري |

| `js/calc.js` | كل حسابات الأرصدة وكشف الحساب |
| `js/store.js` | تحميل البيانات في الذاكرة وإعادة الرسم بعد أي تعديل |
| `js/views.js` | الشاشات: الرئيسية، العمليات، العهدة، التقارير، الحسابات، الإعدادات، البنود |

| `js/txform.js` | شيت تسجيل/تعديل عملية |

| `supabase.sql` | جدول المزامنة وصلاحياته، بيتشغل مرة واحدة في Supabase |
| `js/export.js` | تصدير كشف الحساب Excel، والنسخ الاحتياطي واسترجاعه |
| `js/i18n.js` | النصوص بالعربي والإنجليزي |
| `js/util.js` | تنسيق الأرقام والتواريخ والترجمة |
| `vendor/` | Dexie 4 وSheetJS 0.18.5 (نسخ محلية عشان الشغل أوفلاين) |
| `sw.js`، `manifest.webmanifest` | الـ PWA: الشغل أوفلاين والتثبيت |

## ملاحظات للتطوير

- المبالغ بتتخزن **بالقرش** (أرقام صحيحة): `toMinor` و`fromMinor` في `util.js`.
- الحذف **ناعم**: العمليات بتاخد `deletedAt` بدل ما تتمسح. كل صف فيه `id` (UUID) و`createdAt` و`updatedAt`، ودي الحقول اللي هتحتاجها المزامنة مع Supabase.
- الأرصدة **مش متخزنة**، كلها بتتحسب من العمليات في `calc.js`.
- الدولار متشال من الواجهة (`hasUSD` في `views.js` بترجع `false`)، بس الحسابات والأرصدة بتدعم أكتر من عملة لو احتجناه.
- البنود اللي ليها `system` ثابتة: `owner_transfer` (تحويل للمالك)، و`adjust_in`/`adjust_out` (تسوية فرق رصيد).
